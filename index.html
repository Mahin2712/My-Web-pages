ESP32 DevKit — The Brain

Acts as the central processing unit for navigation. It manages the Front and Rear Sonar arrays, the precision VL53L0X LIDAR sensor, and GPS telemetry. It runs the core decision-making loop for pathfinding and obstacle avoidance.

ESP32-CAM — The Muscle & Eyes

Dedicated to visual data handling. It manages WebSocket-based high-framerate video streaming to the operator dashboard and executes emergency hardware motor overrides when remote intervention is required.

memory Hardware Specifications

Powered by precision actuator motors. The high-torque MG995 servo handles heavy horizontal panning and target tracking, while the rapid MG90S pusher servo triggers the physical engagement mechanism. Initial motion acquisition is handled via a high-sensitivity PIR sensor array.

Operational Modes

gpp_bad

Security Mode

AUTONOMOUS

Total system autonomy. The turret instantly aligns and fires upon confirmed target detection. It simultaneously fires a Telegram WebHook to alert the operator that an engagement has taken place.

gpp_good

Friendly Mode

HUMAN-IN-LOOP

Safe operation with human oversight. Detects the target, tracks it, calculates distance, and alerts the operator via Telegram. It enters a holding pattern for up to 15 seconds awaiting engagement approval via an inline keyboard.
